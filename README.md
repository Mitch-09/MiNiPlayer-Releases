# MiNi Player Dev – Releases

Dieses öffentliche Repository dient ausschließlich der Verteilung freigegebener **Development-APKs**, ihrer Update-Metadaten und Prüfsummen. Der Quellcode bleibt privat.

**Ersteinrichtung läuft: Es wurde noch keine signierte Development-APK veröffentlicht.** Sobald die dauerhafte Signierung eingerichtet und ein Release freigegeben ist, erscheint es unter [Releases](https://github.com/Mitch-09/MiNiPlayer-Releases/releases). Development-Versionen werden dort als Prerelease markiert.

## Installation auf Google TV / Android TV

- Ausschließlich eine signierte `MiNiPlayer-Dev-VERSION-CODE.apk` aus einem veröffentlichten Release verwenden. Debug-/tvTest-Builds sind keine dauerhaften Dev-Installationen.
- APK, `update.json` und `SHA256SUMS` gehören zum selben Release. APK-Prüfsumme und Signaturzertifikat vor der ersten Installation unabhängig prüfen.
- Android verlangt die Freigabe der gewählten Installationsquelle und eine ausdrückliche Installationsbestätigung.
- **Eine bisherige MiNiPlayer-App nicht deinstallieren und ihre Daten nicht löschen.** MiNi Player Dev ist als eigenes Paket parallel installierbar und besitzt einen getrennten Datenbereich. Playlists und Favoriten werden nicht automatisch übernommen.
- Spätere Dev-Updates: Einstellungen → Über MiNi Player → Nach Updates suchen. Installation erfolgt weiterhin mit Androids Benutzerbestätigung.

Die App liefert keine Sender, Filme, Serien oder IPTV-Zugangsdaten mit. Eigene rechtmäßig nutzbare Quellen werden auf dem jeweiligen Gerät eingerichtet. Dieses Repository enthält keine privaten Schlüssel, Tokens oder Nutzerkonfigurationen und dient nicht der Google-Play-Verteilung.
